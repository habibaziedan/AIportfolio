## Featured Project

**Dalil (دليل) — AI-Powered University Assistant**
Team-led graduation project (Grade: A). A Retrieval-Augmented Generation assistant giving students, professors, and staff instant, accurate answers to university-related queries, grounded in real institutional data. Built with HuggingFace embeddings, FAISS, Groq-hosted LLaMA 3.1, LangChain, and a FastAPI backend, with bilingual (Arabic/English) support across web and Flutter mobile.

## Methodology

The project follows: BRD → PRD → Epic → Stories → Tasks → Implementation → Testing → Deployment.

AI tools were used as development assistants, with generated outputs reviewed and evaluated before implementation, per the AI Usage & Evaluation Methodology in the project's BRD/PRD documentation.

```bash

```

Then visit `http://localhost:8000`.
