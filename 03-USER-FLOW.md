# User Flow

## 3.1 Main Recruiter Journey

```
START
  │
  ▼
Open Portfolio
  │
  ▼
Home / Hero
  │
  ▼
View Projects  OR  View About
  │
  ▼
Review Project Details / Experience
  │
  ▼
View Skills
  │
  ▼
Decide whether to learn more
  │
  ▼
View CV
  │
  ▼
Open GitHub / LinkedIn
  │
  ▼
Contact
  │
  ▼
END
```

The primary user flow is intentionally short: **Identity → Evidence → Skills/Experience → CV → Contact.**

This flow is reflected directly in the portfolio's navigation order and in the waypoint markers running down the page.
