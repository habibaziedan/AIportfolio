# Website Information Architecture

```
PERSONAL AI PORTFOLIO
│
├── Home        — Name, AI/ML title, positioning, CTA
├── About       — Introduction, Education, Interests
├── Skills      — AI/ML, Programming, Technologies
├── Experience  — Internships
├── Projects    — Dalil, Machine Learning, NLP, Computer Vision
└── Contact     — Email, LinkedIn, GitHub, CV
```

This IA maps one-to-one to the sections and navigation in `index.html`.
